# Tic-Tac-Toe AI using Minimax

## Description
This project is a simple Tic-Tac-Toe game where a human player plays against an AI. The AI uses the Minimax algorithm, making it unbeatable.

## Features
- Human vs AI gameplay
- Unbeatable AI using Minimax
- Input validation
- Detects win and draw conditions

## How to Run
1. Open terminal
2. Run:
   python main.py

## Technologies Used
- Python

## Algorithm Used
Minimax Algorithm
